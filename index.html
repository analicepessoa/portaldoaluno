🤖 Texto do Prompt (junto com as Perguntas Abertas)

Opcional. Quando o aluno clicar em "Copiar respostas", ele leva este texto pronto para colar na IA. Há 2 jeitos:

  • Prompt pronto (recomendado): escreva o prompt completo e coloque {{codigo}} onde a resposta do aluno deve entrar — usando o Código da variável que você definiu em cada pergunta. Ex.: "...uma landing page para a {{nome_negocio}}, do ramo de {{nicho}}, em {{cidade}}." Também funciona por número: {{1}}, {{2}}...
  • Simples: se você não usar nenhum {{ }}, este texto entra antes de uma lista com as perguntas e respostas.
