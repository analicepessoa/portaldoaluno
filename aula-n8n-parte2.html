Aula 2 — Juntando tudo: Google Sheets + IA (Groq) + Telegram em um único workflow

📋 Sobre esta aula

Na aula passada, configuramos três peças separadas: a leitura da planilha, a IA da Groq e o bot do Telegram. Hoje vamos ligar essas três peças em um único workflow, para que o n8n faça tudo sozinho: leia os contatos com status "Aguardando", peça pra IA escrever uma mensagem pra cada um, envie pelo Telegram, e depois marque na planilha que aquele contato já foi atendido.

Objetivos da aula:

  • Entender por que precisamos de um "Chat ID" e não do telefone para enviar mensagens no Telegram
  • Ligar o node do Google Sheets ao node da Groq
  • Ligar a resposta da IA ao envio pelo Telegram
  • Atualizar a planilha automaticamente, trocando o status de "Aguardando" para "Enviado"
  • Testar o workflow completo e (opcional) programar para rodar sozinho todos os dias

1

Um ajuste importante na planilha: o Chat ID

Por que não dá pra usar só o telefone?

Diferente do WhatsApp, um bot do Telegram não pode iniciar conversa com alguém só porque tem o número de telefone da pessoa. Ele só consegue mandar mensagem pra quem já mandou pelo menos uma mensagem pra ele antes. Por isso, em vez do telefone, cada contato da planilha precisa ter o Chat ID — um número que identifica a conversa entre aquela pessoa e o seu bot.

⚠️ Isso muda a planilha. Precisamos adicionar uma coluna nova chamada CHATID. A boa notícia é que a nossa planilha já tem uma coluna com número único por linha, a N° — vamos usar ela (ou o row_number que o próprio n8n gera) para o n8n saber qual linha atualizar depois.

Como descobrir o Chat ID de cada contato

  1. Peça para cada contato mandar uma mensagem qualquer (tipo "oi") para o seu bot no Telegram.
  2. No n8n, crie um workflow novo, temporário, só com o node "Telegram Trigger", escutando por mensagens.
  3. Ative o modo de escuta ("Listen for test event") e peça para o contato mandar a mensagem.
  4. O n8n vai mostrar o JSON recebido — dentro dele tem um campo chat.id. Esse é o Chat ID.
  5. Copie esse número para a coluna ChatID da linha daquele contato, na planilha.

A planilha atualizada fica assim (mantendo as colunas que já existem, só acrescentando CHATID):

1Maria Souza(12) 99999-0001maria@email.com——123456789Aguardando
2João Lima(12) 99999-0002joao@email.com——987654321Enviado

💡 Fique de olho nas maiúsculas. Na nossa planilha o status é escrito como Aguardando e Enviado (com inicial maiúscula). O filtro e a atualização precisam usar exatamente essa grafia — se escrever "aguardando" tudo minúsculo, o n8n não vai encontrar nada.

Montando o fluxo completo

Vamos construir este caminho no canvas:

Manual Trigger
→
Google Sheets
(Get rows,
status = Aguardando)
→
Basic LLM Chain
+ Groq Chat Model
→
Telegram
(Send message)
→
Google Sheets
(Update row,
status = Enviado)

2.1 — Trigger e leitura da planilha

  1. Comece com um "Manual Trigger" (o mesmo "Test workflow" de sempre, por enquanto).
  2. Conecte o node do Google Sheets que já configuramos na aula passada (Get row(s), filtrando STATUS = Aguardando).

2.2 — Gerando a mensagem com a IA

  1. Adicione um node "Basic LLM Chain", conectado na saída do Google Sheets.
  2. No campo Chat Model, conecte o "Groq Chat Model" que já configuramos, usando a mesma credencial da aula passada.
  3. No campo de Prompt, escreva algo como:
    Escreva uma mensagem curta e simpática avisando {{ $json.NOME }} que o atendimento dele já está disponível.
  4. Repare que {{ $json.NOME }} é uma expressão — ela pega o valor da coluna "NOME" daquele contato específico, e muda automaticamente para cada linha.
  5. Clique em "Test step" e veja a IA gerar uma mensagem personalizada para cada contato da lista.
💡 O que é essa "chave { }"? É como uma variável: em vez de escrever "Maria" fixo no texto, a expressão {{ $json.Nome }} diz para o n8n "coloque aqui o nome desta linha". Assim a mesma mensagem-modelo funciona para todos os contatos, cada um recebendo o próprio nome.

2.3 — Enviando pelo Telegram

  1. Adicione o node Telegram (ação "Send a text message"), conectado na saída do "Basic LLM Chain".
  2. No campo Chat ID, use a expressão {{ $('Google Sheets').item.json.CHATID }} (assim ele busca o ChatID lá da planilha, não do resultado da IA).
  3. No campo Text, use {{ $json.text }} (ou o nome do campo de saída do "Basic LLM Chain" — confira o nome exato no painel de resultado do node anterior).

2.4 — Atualizando o status na planilha

  1. Adicione mais um node Google Sheets, agora com a ação "Update Row".
  2. Selecione a mesma planilha e a mesma aba.
  3. Em "Column to match on", escolha row_number (recomendado — é gerado automaticamente pelo n8n e garante a linha certa) ou N°, se preferir usar a numeração da própria planilha.
  4. No campo de valor dessa coluna, use uma expressão puxando do node anterior, por exemplo {{ $('Google Sheets').item.json.row_number }}.
  5. Em STATUS, escreva o valor fixo Enviado (com o mesmo padrão de maiúscula/minúscula que já usamos na planilha).
⚠️ Apague os campos que você não quer alterar. Quando você abre o node "Update Row", ele pode trazer automaticamente campos como NOME, NUMERO, EMAIL, ESCOLHA e DATA vazios (aparecendo como [empty]). Se deixar assim, o n8n entende que é para apagar o conteúdo dessas colunas! Clique no ícone de lixeira 🗑️ ao lado de cada um desses campos vazios para removê-los da lista. No final, deve sobrar só o campo STATUS para preencher.
✅ Ponto de checagem: antes de testar, confira que a lista de campos do node "Update Row" mostra somente a coluna STATUS (além da coluna de referência lá em cima, no "Column to match on"). Se aparecer qualquer outro campo vazio na lista, apague-o.

🧠 Por que usamos "row_number" (ou "N°") para atualizar a linha certa, em vez de "NOME"?

3

Testando o workflow completo

Antes de tudo: teste com 1 ou 2 contatos

Para o primeiro teste, deixe só 1 ou 2 linhas com status "Aguardando" na planilha (mude as outras temporariamente, ou use uma cópia da planilha para teste). Assim, se algo estiver errado, poucos contatos recebem mensagem.

  1. Clique em "Test workflow", no canto do canvas.
  2. Observe cada node ficar verde (sucesso) ou vermelho (erro), na ordem em que são executados.
  3. Clique em cada node para ver os dados que passaram por ele — isso ajuda muito a entender e a corrigir erros.
  4. Confira no seu Telegram se a mensagem chegou certinha.
  5. Confira na planilha se o status daquela linha virou "Enviado".
✅ Ponto de checagem: se tudo deu certo, rodar o workflow de novo não deve reenviar mensagem para quem já está com status "Enviado" — porque o filtro do Google Sheets só traz quem está "Aguardando".
4

Automatizando (opcional)

Depois que o teste manual estiver funcionando bem, dá para trocar o "Manual Trigger" por um "Schedule Trigger", para que o workflow rode sozinho em horários definidos (por exemplo, todo dia às 9h da manhã).

  1. Remova (ou desative) o node "Manual Trigger".
  2. Adicione o node "Schedule Trigger" e conecte na entrada do Google Sheets.
  3. Configure o intervalo desejado (ex: "Every day" às 09:00).
  4. Salve e ative o workflow (botão "Active", no topo direito).
💡 Fica ligado só se estiver ativo. O workflow só roda sozinho se o botão "Active" estiver ligado. Enquanto estiver desligado, ele só executa quando você clicar em "Test workflow".
5

Cuidados antes de usar de verdade

  • Sempre teste com poucos contatos antes de rodar com a planilha inteira
  • Confira se a coluna "ID" realmente não tem números repetidos
  • Guarde uma cópia de segurança da planilha antes da primeira execução automática
  • Releia a mensagem gerada pela IA algumas vezes — ela pode variar, então vale revisar o tom antes de deixar 100% automático
  • Lembre-se: só é possível mandar mensagem para quem já iniciou conversa com o bot (tem ChatID)

Manual/Schedule Trigger → Google Sheets (buscar "Aguardando") → Basic LLM Chain + Groq (gerar mensagem) → Telegram (enviar) → Google Sheets (marcar "Enviado").
