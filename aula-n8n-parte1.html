O que é o n8n?

Uma linha de produção digital

Pense numa fábrica: uma esteira vai passando por várias estações, e em cada estação alguém (ou alguma máquina) faz uma tarefa — corta, pinta, embala. O n8n funciona assim, só que com informação: dados entram, passam por várias "estações" (que chamamos de nodes, ou "nós"), e saem já prontos, sem que ninguém precise fazer aquele trabalho manualmente todo dia.

Vocabulário básico

  • Workflow: o fluxo inteiro, do começo ao fim — é o nome que damos para cada "automação" que criamos.
  • Node (nó): cada caixinha do fluxo. Cada node faz uma coisa: ler uma planilha, mandar uma mensagem, perguntar algo para uma IA, etc.
  • Trigger (gatilho): o node que dá o pontapé inicial — o que faz o workflow começar a rodar (pode ser manual, um horário programado, ou um evento como "chegou uma mensagem nova").
  • Credencial: a "chave de acesso" que autoriza o n8n a usar sua conta do Google, do Telegram, da Groq, etc.
💡 Por que isso é útil? Imagine que toda semana você precisa olhar uma planilha, ver quem ainda não recebeu uma mensagem, escrever essa mensagem e mandar no Telegram, uma pessoa de cada vez. Com o n8n, essas etapas viram um fluxo automático — o computador faz o trabalho repetitivo, e você cuida do que realmente importa.

Criando sua conta e conhecendo a interface

Passo a passo para criar a conta

  1. Acesse n8n.io e clique em "Start for free" (ou "Comece grátis").
  2. Cadastre-se com seu e-mail (ou conta Google).
  3. Confirme o e-mail, se for solicitado.
  4. Você vai cair direto no editor de workflows, com um espaço em branco chamado canvas.

Conhecendo o canvas

  • Área central (canvas): onde os nodes ficam e se conectam por linhas.
  • Botão "+" ou "Add first step": usado para adicionar um novo node.
  • Botão "Execute workflow" / "Test workflow": roda o fluxo manualmente, para testarmos.
  • Painel de configuração do node: abre ao clicar duas vezes em um node, e é onde preenchemos os detalhes (qual planilha, qual mensagem, etc.).
✅ Ponto de checagem: antes de seguir, confirme que todos os alunos conseguem ver o canvas vazio e sabem localizar o botão de adicionar um node.

Conectando o Google Sheets e filtrando por status

Nossa planilha de exemplo

Vamos usar uma planilha de contatos parecida com esta:

NomeTelefoneStatus
Maria Souza(12) 99999-0001aguardando
João Lima(12) 99999-0002enviado
Ana Paula(12) 99999-0003aguardando

O objetivo desta etapa é fazer o n8n ler essa planilha e trazer apenas as linhas com status "aguardando" — ou seja, só os contatos que ainda não receberam nada.

Passo a passo

  1. No canvas, clique em "+" e pesquise por "Google Sheets".
  2. Escolha a ação "Get row(s) in sheet" (buscar linhas na planilha).
  3. Em Credential, clique em "Create new credential" e siga o login do Google, autorizando o n8n a acessar suas planilhas.
  4. Em Document, cole o link da sua planilha (ou selecione na lista).
  5. Em Sheet, selecione a aba correta (geralmente a primeira aba).
  6. Ative a opção "Filters" (ou "Combine Filters", dependendo da versão) e adicione uma condição:
    Coluna: Status  |  Condição: igual a  |  Valor: aguardando
  7. Clique em "Test step" para rodar só este node e conferir o resultado.
⚠️ Atenção com maiúsculas e espaços: o filtro compara o texto exatamente como está escrito. Se na planilha estiver "Aguardando" (com A maiúsculo) ou " aguardando" (com espaço extra), o filtro pode não encontrar nada. Combine com a turma que todos vão escrever "aguardando" sempre da mesma forma.
✅ Ponto de checagem: ao clicar em "Test step", o resultado deve mostrar somente os contatos com status "aguardando". Se aparecer tudo, revise o filtro.

Configurando uma IA com a Groq

O que é a Groq?

A Groq é uma empresa que oferece acesso a modelos de inteligência artificial (como o Llama) de um jeito extremamente rápido, e com um plano gratuito generoso — por isso é uma ótima opção para quem está aprendendo.

Passo a passo: gerando a chave de API

  1. Acesse console.groq.com e crie sua conta (pode ser com o Google).
  2. No menu, vá até "API Keys".
  3. Clique em "Create API Key", dê um nome (por exemplo, "n8n") e confirme.
  4. Copie a chave gerada — ela só aparece completa uma vez, então guarde em um lugar seguro.
⚠️ Nunca compartilhe sua API Key. Ela funciona como uma senha: quem tiver essa chave pode usar seus créditos na Groq. Não cole a chave em grupos, prints ou vídeos.

Passo a passo: configurando no n8n

  1. No canvas, clique em "+" e pesquise por "Groq".
  2. Selecione o node "Groq Chat Model".
  3. Em Credential, clique em "Create new credential" e cole a API Key copiada da Groq.
  4. Em Model, escolha um modelo da lista (o n8n carrega automaticamente os modelos disponíveis na sua conta).
  5. Para testar rapidamente, adicione também um node "Basic LLM Chain" conectado ao "Groq Chat Model", escreva uma pergunta simples no campo de prompt (por exemplo, "Diga oi em uma frase") e clique em "Test step".
✅ Ponto de checagem: ao testar, a IA deve responder com um texto. Se der erro de autenticação, confira se a API Key foi colada corretamente, sem espaços antes ou depois.

Conectando o Telegram

Criando o bot no Telegram

No Telegram, todo robô (bot) precisa ser criado através de outro bot especial, chamado @BotFather.

  1. Abra o Telegram e pesquise por @BotFather.
  2. Envie o comando /newbot.
  3. Escolha um nome de exibição para o bot (ex: "Bot da All Net").
  4. Escolha um nome de usuário único, que precisa terminar em bot (ex: allnet_avisos_bot).
  5. O BotFather vai te enviar um token — uma sequência longa de letras e números. Copie esse token.
⚠️ O token do bot também é uma senha. Quem tiver o token consegue controlar o bot inteiro. Guarde com o mesmo cuidado que a API Key da Groq.

Passo a passo: configurando no n8n

  1. No canvas, clique em "+" e pesquise por "Telegram".
  2. Para testar o envio, escolha a ação "Send a text message".
  3. Em Credential, clique em "Create new credential" e cole o token recebido do BotFather.
  4. Em Chat ID, informe o ID do seu chat com o bot (para descobrir, mande uma mensagem qualquer para o bot e depois use o node "Telegram Trigger" em modo de teste, que mostra o Chat ID recebido).
  5. Escreva uma mensagem de teste no campo Text e clique em "Test step".
✅ Ponto de checagem: a mensagem de teste deve chegar no seu Telegram em poucos segundos. Se não chegar, confira se você já enviou pelo menos uma mensagem para o bot antes (bots não podem iniciar a conversa).
